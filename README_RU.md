# Оракул PWA 0.1

## Что уже работает
- Адаптивный интерфейс для телефона и компьютера.
- История сообщений и заметки в localStorage текущего браузера.
- Поиск по библиотеке, редактирование и удаление заметок.
- Экспорт/импорт резервной копии JSON.
- PWA-оболочка для установки при работе через HTTPS/localhost.

## Важно
ИИ не подключён, ответы пока демонстрационные. Данные не синхронизируются между устройствами автоматически. Не сохраняйте пароли и особо чувствительные сведения. Локальное хранилище браузера может очищаться настройками устройства.

## Запуск на Windows
1. Распакуйте папку `oracle_pwa` в удобное место, например `C:\\OraclePWA`.
2. Установите Python 3, если он не установлен.
3. Откройте папку в Проводнике, щёлкните адресную строку, введите `cmd` и нажмите Enter.
4. Выполните `python -m http.server 8000`.
5. Откройте `http://localhost:8000`.
6. Для остановки нажмите Ctrl+C в окне командной строки.

## iPhone
Для теста откройте приложение через локальную сеть: узнайте IP компьютера командой `ipconfig` и на iPhone в той же Wi-Fi-сети откройте `http://IP-КОМПЬЮТЕРА:8000`. Например, `http://192.168.1.25:8000`. Может понадобиться разрешить соединение в брандмауэре Windows. Это только тестовая схема; для безопасной постоянной установки нужен HTTPS-хостинг.

## Безопасность
Никогда не помещайте секретные API-ключи в `app.js`, HTML или публичный репозиторий. Храните их только на сервере в переменных окружения/секретах хостинга. Для публикации необходимы авторизация, проверка доступа к каждой записи, лимиты запросов, ограничения загрузки файлов и резервные копии. Для настоящей синхронизации замените localStorage на защищённый backend.
